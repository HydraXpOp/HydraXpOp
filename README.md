## How I Like to Work

- **Build, don't just watch.** I try to turn what I learn into working projects instead of only following tutorials.
- **Understand the problem.** When something breaks, I want to know why before trying random fixes.
- **Keep code readable.** Even in small practice projects, I try to use clear structure and meaningful names.
- **Be honest about progress.** I make it clear when something is incomplete, experimental, or still improving.
- **Use Git intentionally.** I aim to write commits that explain what changed and keep project history organised.
- **Improve consistently.** I prefer completing manageable tasks one by one over making a huge plan and never starting it.

> **Consistency beats intensity.** A small, finished improvement every week is more valuable than a big plan that never becomes real work.
